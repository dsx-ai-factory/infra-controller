## [v2.4.0] - 2026-10-22

### Added

- **Breaking:** Require serviceID and an explicit deployInCluster: false in DPF Helm extension-service data; clients must supply both when creating service versions. serviceID is immutable and unique case-insensitively among active managed services, and live DPUService identity is checked during creation and recovery. See [https://nvidia.github.io/infra-controller/](https://nvidia.github.io/infra-controller/) for the updated schema. ([#6975](https://github.com/dsx-ai-factory/infra-controller/pull/6975))
- **Breaking:** Add explicit Flow tracing enablement independent of the collector endpoint while retaining trace-context propagation when export is disabled. Non-Helm deployments that previously enabled export using only an endpoint must set `tracing.enabled: true` and restart; Helm enables export by default. ([#7329](https://github.com/dsx-ai-factory/infra-controller/pull/7329))
- **Breaking:** Unify standalone bmc-mock and machine-a-tron persistence with portable snapshots and atomic writes, including retry and shutdown flushing.
