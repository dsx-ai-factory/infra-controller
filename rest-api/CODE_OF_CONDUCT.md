# Code of Conduct

The repository-wide [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) is canonical
for the `rest-api/` tree. It defines the participation standards, confidential
reporting path, enforcement process, recusal requirements, and appeal process
for all NICo community spaces and contributors.

Report conduct incidents as described in the root policy. Do not report conduct
incidents through public GitHub issues, pull requests, or Discussions.
