# nvidia.infra_controller.sku_info – query SKU

Retrieve all SKUs

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | `str` | No | ID of the resource to retrieve. |
| `site_id` | `str` | Yes | ID of the Site to retrieve SKUs from |

## Examples

```yaml
- name: List all SKU resources
  nvidia.infra_controller.sku_info:
    api_url: "{{ api_url }}"
    api_token: "{{ api_token }}"
    org: "{{ org }}"
    site_id: "{{ site_id }}"

- name: Get a specific SKU by ID
  nvidia.infra_controller.sku_info:
    api_url: "{{ api_url }}"
    api_token: "{{ api_token }}"
    org: "{{ org }}"
    site_id: "{{ site_id }}"
    id: "{{ resource_id }}"
```
