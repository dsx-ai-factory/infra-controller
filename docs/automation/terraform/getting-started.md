# Getting Started with the NICo Terraform Provider

The `nico` Terraform provider lets you manage NICo resources declaratively in HCL —
machines, VPCs, allocations, instances, networking, and more — with full `terraform plan`
previews, drift detection, and `terraform import` support.

## Installation

> **Note:** The provider is not yet published to the Terraform Registry. Once registered,
> install it as shown below. Until then, build from source at
> [dsx-ai-factory/terraform-provider-nvidia-infra-controller](https://github.com/dsx-ai-factory/terraform-provider-nvidia-infra-controller)
> and use a [`dev_overrides`](https://developer.hashicorp.com/terraform/cli/config/config-file#development-overrides-for-provider-developers) block in your CLI config.

```hcl
terraform {
  required_providers {
    nico = {
      source  = "dsx-ai-factory/nvidia-infra-controller"
      version = "~> 2.1"
    }
  }
}
```

Then run:

```bash
terraform init
```

## Authentication

Configure the provider with your NICo API credentials:

```hcl
provider "nico" {
  api_url   = var.nico_api_url    # or set NICO_API_URL
  api_token = var.nico_api_token  # or set NICO_API_TOKEN
  org       = var.nico_org        # or set NICO_ORG
}
```

Store credentials in Terraform variables backed by a secrets manager rather than in plaintext.

## Example configuration

```hcl
resource "nico_vpc" "main" {
  site_id = var.site_id
  name    = "production"
}

resource "nico_allocation" "gpu" {
  site_id = var.site_id
  name    = "gpu-pool"
}

data "nico_machine" "worker" {
  site_id = var.site_id
}
```

## Provider source repository

The provider Go source lives in
[dsx-ai-factory/terraform-provider-nvidia-infra-controller](https://github.com/dsx-ai-factory/terraform-provider-nvidia-infra-controller).
Go files under `internal/provider/` are generated automatically from the NICo OpenAPI spec
at each release by `tools/generate/generate.py --backend terraform` in this repository.

## Resource and data source reference

Once the provider is published, the full resource and data source reference will be available on the
[Terraform Registry page](https://registry.terraform.io/providers/dsx-ai-factory/nvidia-infra-controller),
generated by `tfplugindocs` from the provider repo.
